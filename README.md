# ne-ti.kz

Лендинг компании **NE-TI** — статические и динамические испытания свай, забивка свай по всему Казахстану. Офис в Астане.

## Структура

- `index.html` — весь сайт (HTML/CSS/JS в одном файле, без сборки)
- `robots.txt` — правила индексации
- `sitemap.xml` — карта сайта для поисковиков

## Как посмотреть локально

Просто открыть `index.html` в браузере — сборка не нужна.

## Деплой

Сайт статический, подойдёт любой из вариантов:

- **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / root
- **Vercel / Netlify**: подключить репозиторий, build command — пусто, output directory — `/`
- Классический хостинг: залить файлы по FTP в корень домена

После деплоя не забыть:
1. Подключить домен `ne-ti.kz` в DNS
2. Проверить `sitemap.xml` и `robots.txt` открываются по адресу `ne-ti.kz/sitemap.xml`
3. Отправить сайт на индексацию через Yandex.Webmaster и Google Search Console
4. Заменить адрес офиса в футере на точный (сейчас указан ориентировочно — Астана, пр. Мәңгілік Ел)

## SEO

- Meta title/description и Open Graph теги — в `<head>` `index.html`
- JSON-LD разметка `ProfessionalService` (schema.org) с адресом и телефоном
- Список релевантных/нерелевантных поисковых запросов — см. ответ в чате при создании проекта

## Индексация в Google и Яндекс — пошагово

**0. Сначала домен.** Подключите `ne-ti.kz` в Vercel (Settings → Domains) и дождитесь, пока он станет основным (`ne-ti.vercel.app` тогда сам сделает редирект). Все шаги ниже делайте уже для `ne-ti.kz`, не для `.vercel.app` — иначе получите две версии сайта в поиске.

### Google Search Console
1. Зайти на [search.google.com/search-console](https://search.google.com/search-console)
2. Добавить ресурс → «Префикс URL» → `https://ne-ti.kz/`
3. Способ подтверждения — «HTML-тег»: скопировать код, вставить в `index.html` вместо `ЗАМЕНИТЕ_НА_СВОЙ_КОД` в строке `google-site-verification`, задеплоить, нажать «Подтвердить»
4. Слева → «Файлы Sitemap» → добавить `sitemap.xml` → отправить
5. Вверху «Проверка URL» → вставить `https://ne-ti.kz/` → «Запросить индексирование» (ускоряет первое сканирование)

### Яндекс Вебмастер
1. Зайти на [webmaster.yandex.ru](https://webmaster.yandex.ru)
2. Добавить сайт → `ne-ti.kz`
3. Подтверждение — «Мета-тег»: код вставить в `index.html` вместо `ЗАМЕНИТЕ_НА_СВОЙ_КОД` в строке `yandex-verification`, задеплоить, подтвердить
4. Раздел «Индексирование» → «Файлы Sitemap» → указать `https://ne-ti.kz/sitemap.xml`
5. «Переобход страниц» → добавить `https://ne-ti.kz/` вручную, чтобы не ждать робота

### Дополнительно (важно для локального SEO услуг по РК)
- Завести **Google Business Profile** и **Яндекс Бизнес / 2ГИС** с адресом в Астане, телефоном и услугами — это отдельный источник трафика и повышает доверие к сайту у поисковиков
- Указывать везде (сайт, GBP, 2ГИС, соцсети) один и тот же телефон/адрес — несовпадения снижают локальное ранжирование
- Раз в 1–2 недели после публикации проверять в GSC раздел «Покрытие» / «Страницы» — там видно, проиндексирована ли страница и нет ли ошибок
- Индексация — не мгновенная: Google обычно 3–14 дней, Яндекс — от нескольких дней до 3 недель
